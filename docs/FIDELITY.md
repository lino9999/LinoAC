# Reconstruction fidelity ledger

The requested objective is a complete working reconstruction of the supplied plugin. It remains open. LinoAC's 175 implemented rule paths and 203 catalogue entries establish implementation coverage; they do not establish 175 completely equivalent detectors. The original and static derivatives were never executed.

## Work still required for the complete objective

- Reconcile every movement, packet and world detector's complete exemption branches, exact sample cadence, reset behavior and finding modes. Existing independent physics/geometry budgets are not exact original client prediction.
- Complete remaining scaffold timing, world branches and staff/integration behavior. FastBreak interaction/start/deadline and LOWEST break authority were recovered in 0.5.0; public Bukkit break speed deliberately replaces the obsolete reference hardness table.
- Verify source JOINED/TELEPORT exclusions before each stateful detector mutates its history. Filtering findings alone does not prove original history continuity. Timer join accumulation is handled explicitly.
- Reconcile remaining staff/integration behaviors against the artifact rather than configuration declarations alone. A connected proxy receiver and real Floodgate/mcMMO environments remain outside current runtime evidence.
- Exercise multiplayer gameplay and relevant modern/legacy client translations. Server startup and synthetic clients do not establish field accuracy or performance improvement.

## Deliberate changes

Lino branding, renamed commands/permissions/aliases and the new API namespace are intentional. Remote licensing, telemetry and downloaded executable code are omitted. Proxy messaging uses independently named LinoAC channel and delimiter defaults.

Known defects are repaired explicitly: Scaffold A's contradictory event dispatcher, unsafe signed teleport matching and repeatable teleport-target reuse. Relative teleport coordinates resolve against a known wire position. Queues, placement history and counters are bounded. Invalid or unknown protocol inputs do not invent known geometry or discard valid pending acknowledgements. These changes are not described as identical original behavior.

Automatic punishments and setbacks remain disabled by default. [Validation](VALIDATION.md) identifies the exact tested artifact and separates fresh results from [0.2.0 historical results](VALIDATION_0.2.0.md).

## 0.4.0 corrections to prior producer assumptions

Position-only packet scope for web, vehicle and entity-crowding ages supersedes the earlier all-movement assumption. Spigot/Paper crowding selects the cached Bukkit nearby list, rather than a union with the mirrored entity count. WEB uses signed vertical delta below 0.1, not horizontal speed or absolute vertical motion. Material snapshots update on actual Bukkit XYZ moves and retain their values across stationary packets and block changes. Timer origin classification uses previous cached floors and waits for material context before updating those floors. Flag/Timer/display TPS now share the recovered PacketEvents metric.

The literal original default counter path increments only Invalid A/B. LinoAC deliberately repairs this defect with the recovered seven category/family counters, excluding experimental/combined findings. Successful automatic dispatch preserves these counters and buffers while clearing current VL; unlike the original, cancelled/empty/failed dispatches do not erase VL or consume cooldown. GhostHand repairs neighboring BEDROCK pairing and honors the cancellable Lino API before local break interception. Unknown geometry is conservatively skipped instead of loading chunks or substituting original SPONGE values.

A genuine inherited-text-default regression affecting upgrades from pre-0.3 configurations was reproduced with the actual Bukkit YAML API and fixed in 0.4.0. Runtime upgrade and fresh-server results are reported separately in VALIDATION.md.

## 0.5.0 recovered behavior and deliberate repairs

Shared transport now distinguishes preceding/following impulse acknowledgements from ordinary state updates confirmed by a later probe. Combat uses raw input clocks, retained target-relative history, fixed empty-history decay and finite velocity candidates. Material/contact ages and event counters preserve distinct initialization, source authority and packet cadence. Per-rule tri-state exemptions prevent absent telemetry from becoming an invented clean value. The published validation report scopes the finite tests separately from runtime evidence.

Automatic enforcement uses a player-wide monotonic cooldown and cancellable pending-action ownership. Accepted reload cancels delayed automatic actions; failed reload preserves them. Local alert cancellation is separate from violation cancellation. Fresh hit suppression uses zero damage with an explicit cancellation mode; old enabled configurations retain their previous cancellation behavior.

Intentional repairs remain explicit: Bedrock exclusion is consolidated through LinoAC's Floodgate/UUID support and `settings.ignore-bedrock`, rather than reproducing four independent reference heuristics. Chorus exemptions use the actual CHORUS_FRUIT material, avoiding reference item-description spoofing. Netherite allowances inspect any equipped netherite item, repairing the first-nonnull-slot reference defect. Cancelled-move grace expires instead of remaining permanently latched. Respawn preserves acknowledged defaults but clears physical impulse context. Explicit reset clears cooldown. Queue loss invalidates the source profile until reconnect; resetting violations does not repair unobserved transport state. Main-thread queue ownership replaces unsafe cross-thread mutation.

NoSlow A is inactive on all supported server versions. Hitbox B remains dormant because its reference target is never assigned; no invented geometry check is substituted. Four empty callbacks and 24 unregistered slots remain unavailable. A complete reconstruction still requires the remaining movement/world consumer and producer audits, gameplay evidence across the target range, and live optional-integration/proxy environments.
