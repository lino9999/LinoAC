# Reconstruction fidelity and deliberate repairs

LinoAC 0.6.0 supplies independent evaluators for every registered nonempty rule path in the supplied artifact. The remaining approximate movement and placement branches have been replaced with recovered input, state, exemption and finding contracts. Defective reference paths are repaired explicitly below. The original and static derivatives were never executed.

Implementation coverage, finite test results and field accuracy are different claims. [VALIDATION.md](VALIDATION.md) identifies the tested JAR and separates pure models, real protocol clients and synthetic Bukkit callbacks. No original-versus-reconstruction runtime replay or comparative performance certification is claimed.

## State and event authority

Bukkit, collectors, detection memory and enforcement remain on the main thread. Network callbacks decode immutable packets into bounded queues and acknowledgement ledgers. Material snapshots use actual Bukkit destination coordinates and retain their frame until another positional event. Unloaded or missing geometry stays unknown.

Raw flying ground/air runs include rotation-only packets. JOINED and material/contact clocks use their recovered position-only cadence. Cached exemptions and direct predicates keep separate processor phases. Raw metadata/action gliding, actual Bukkit gliding and cached chest equipment are independent inputs.

Mounted raw pose, packet count and contact clocks advance on actual VEHICLE_MOVE. Actual positional PlayerMoveEvent callbacks read that retained cache; rotation-only Bukkit movement does not evaluate it. NoSaddle uses only that Bukkit authority. Waterlogged event resets apply before mounted Bukkit evaluation without a duplicate reset on the next position packet. Sulfur uses the acknowledged client block mirror at the actual player or vehicle coordinates.

Unknown state never becomes invented AIR, zero velocity or a clean exemption bit. Where exact age is lost, a documented consecutive known-negative run can establish a lower bound sufficient for the current predicates. Continued unknown samples cannot age out uncertainty. Packet-state loss requires reconnect; violation reset does not reconstruct unobserved transport state.

## Deliberate repairs and independent choices

- Hitbox B now consumes actual attack targets and independent finite angular geometry. Its original private target was never assigned. The configurable maximum angle defaults to 45 degrees.
- NoSlow B keeps the soul-sand, alignment, effect budget and exemption contracts while omitting the permanently true reference walk-speed guard. The acknowledged custom movement-speed exclusion remains.
- Jesus D uses actual feet AIR above the liquid plane. The reference simultaneously required all nine blocks below to be liquid and the center of that same plane to be AIR, making its coherent-frame predicate impossible.
- Scaffold A's contradictory dispatcher, Scaffold C's unassigned timing state and Scaffold H's contradictory sensitivity bounds are repaired with explicit event authority and independent state.
- Teleport matching uses safe finite coordinates, resolves relative targets against known state and consumes candidates once. Signed matching defects and repeatable target reuse are not reproduced.
- The boat-hook exemption follows actual hook UUIDs and lifetime, with forty ticks of observed release grace. Bounded tracking and complete-scan recovery replace the original indefinitely growing entity-ID map. Truncated negative scans remain unknown.
- NoSaddle owns its dismount option independently. It does not inherit the original field that was overwritten by an unrelated empty packet check. Accepted findings, current configuration and the same session/mount are required; reset, logout and accepted reload cancel pending actions.
- Cumulative category/family counters repair the reference's invalid-only default branch. Failed, empty or cancelled punishment dispatch does not erase VL or consume cooldown. Successful automatic dispatch clears current VL while preserving buffers and cumulative history.
- Bedrock handling uses LinoAC's Floodgate/UUID policy. Chorus uses the actual material, netherite considers equipped items, cancelled-move grace expires, and main-thread ownership replaces unsafe shared mutation. Counters and queues are bounded.
- Public Bukkit break speed replaces the obsolete reference hardness table. Proxy channel, delimiter, commands, permissions, API namespace, messages and project assets belong to LinoAC. Remote licensing, telemetry and executable downloads are omitted.

The full LIQUID contact predicate includes water, lava and bubble inputs. This corrects an earlier reconstruction assumption that considered only bubble contact. It is separate from the bubble-specific diagnostic age and the all-liquid surface plane.

## Validation boundaries

The complete implementation is not a guarantee of zero false positives. Multiplayer field accuracy, custom mechanics, translated legacy clients and comparative performance need server-specific evaluation. Live Floodgate, mcMMO and a connected proxy receiver are outside the documented local runtime matrix. Folia is unsupported; the target platforms are Spigot and Paper 1.21.11 through 26.3. These are validation/platform boundaries, rather than hidden catalogue implementations.
