LinoAC by Lino completes the independent movement and placement evaluators, restores defective detection paths and adds explicit mounted packet/event authority. All 203 catalogue entries are documented: 175 registered nonempty paths have evaluators, four empty callbacks and 24 missing upstream implementations stay disabled. ## Changes

- All 51 movement IDs have explicit domain owners. Recovered horizontal phase tables, airborne prediction, impulse allowances, surface/climbing rules, elytra and heading replace the remaining generic branches.
- Mounted movement uses actual VEHICLE_MOVE plus positional Bukkit callbacks. Live type capabilities preserve CamelHusk and inherited Llama behavior. Optional per-check dismount actions default off and honor accepted violations, current mount/session and delayed-action cancellation.
- Hitbox B consumes real attack targets. NoSlow B and Jesus D restore rules blocked by contradictory reference predicates. Placement variants have independent timing windows and event authority; AirPlace cancellation has its own setting and respects API veto.
- Acknowledged modern sulfur contact uses a bounded client block mirror. Physical gliding, equipment, metadata/action state, raw ground/air runs and position-only clocks remain distinct.
- Eight missing named exemption inputs discovered during runtime verification are now connected. The provider audit covers the full consumer dependency set; missing physical facts remain unknown instead of becoming fabricated clean values.
- Log pages show actual totals and distinct unavailable/read-failure results. File quotas apply to the first record too. Cancelled damage callbacks do not reset accepted damage-cause clocks.
- Commands, permissions, aliases, messages, API namespace and assets use LinoAC/Lino. No original classes, assets, licensing, telemetry or executable downloads are packaged.

## Installation

Use Spigot or Paper 1.21.11 through 26.3, Java 21 for 1.21.11 or Java 25 for 26.x, and the full [PacketEvents 2.14.0 release](https://github.com/retrooper/packetevents/releases/tag/v2.14.0). Replace the plugin JAR and restart. Existing configurations inherit new defaults. Automatic punishments, setbacks, ghost repair and mounted dismount default off; review the independent local cancellation settings.
